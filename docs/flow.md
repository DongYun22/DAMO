# DAMO 화면 흐름

## 1. 문서 목적

이 문서는 DAMO MVP의 모바일 웹 화면, 사용자 이동 경로, 모임과 투표의 상태 변화를 정의한다.

- 모든 사용자는 하나의 통합 웹 서비스 `damo.com`에서 시작한다.
- 모임장과 모임원을 구분하지 않고, 로그인한 사용자는 누구나 모임을 만들거나 가입할 수 있다.
- 모임을 만든 사용자가 해당 모임의 모임장이 된다.
- 모든 사용자는 개인별 `내 장소`를 저장하고 관리할 수 있다.
- 후보 선택 화면에는 모든 `내 장소`를 표시하고 모임 목적·성격 일치도를 선택 판단에 활용한다.
- 모임 생성 시 만나는 날짜와 시각을 정한다.
- 모임장은 투표를 수동으로 종료하고 최종 결과를 확정한다.

## 2. 핵심 용어

| 용어 | 의미 |
| --- | --- |
| 계정 닉네임 | 사용자 계정에 저장된 기본 닉네임 |
| 모임 닉네임 | 특정 모임에서 사용하는 닉네임. 계정 닉네임이 기본값이며 수정할 수 있다. |
| 내 장소 | 사용자가 지도에서 저장한 개인 장소 목록 |
| 가입 코드 | 모임 생성 시 자동으로 발급되는 4자리 숫자 |
| 후보 장소 | 모임원이 자신의 `내 장소`에서 선택해 현재 모임의 투표에 제출한 장소 |
| 모임장 | 모임을 생성한 사용자 |
| 모임원 | 가입 코드를 통해 모임에 참여한 사용자. 모임장도 투표에서는 모임원과 동일하게 참여한다. |
| 진행 중인 모임 | 상태가 `모집 중`, `투표 진행 중`, `공동 1위 선택 대기`인 모임 |
| 후보 고정 | 투표 생성 시점의 후보와 추천자 정보를 이후 변경할 수 없도록 저장하는 처리 |

## 3. 확정된 운영 규칙

### 3.1 계정과 로그인

- 모임장과 모임원 모두 계정 로그인이 필요하다.
- 로그인하지 않은 사용자는 모임 생성, 가입, 장소 저장, 후보 선택, 투표를 할 수 없다.
- 배포 이전 테스트 단계에서는 다음 로그인 방식을 모두 제공한다.
  - 아이디·닉네임·비밀번호로 즉시 가입하는 테스트 로그인
  - 카카오 OAuth
  - 네이버 OAuth
  - 구글 OAuth
- 실제 배포 시에는 테스트 가입·로그인을 제거하고 OAuth 로그인만 제공한다.
- 카카오·네이버·구글 계정은 이메일이 같더라도 자동으로 통합하지 않고 로그인 제공자별 별도 계정으로 관리한다.
- MVP 사용자 프로필에는 로그인 제공자, 닉네임, 이메일을 저장하며 프로필 사진은 사용하지 않는다.
- 초대 링크를 로그인하지 않은 상태로 열면 로그인 화면으로 이동한다.
- OAuth 로그인 완료 후에는 홈 화면으로 이동한다.
- 초대 링크에서 로그인한 사용자도 홈 화면의 `모임 가입하기`에서 4자리 코드를 입력해 가입한다.

### 3.2 모임 생성

- 로그인한 사용자는 누구나 모임을 생성할 수 있다.
- 모임 생성 시 다음 항목을 각각 하나씩 선택한다.
  - 모임 이름
    - 최대 20글자
  - 정원
    - 최소 2명
    - 최대 인원 제한 없음
  - 만나는 날짜
  - 만나는 시각
    - 오전/오후
    - 시: `1~12`
    - 분: `00` 또는 `30`
  - 모임 목적: `스터디`, `카페`, `식사`, `술 한잔`
  - 모임 성격: `즐거운`, `조용한`, `격식있는`, `취기있는`
- 모임을 만든 사용자가 모임장이 된다.
- 모임 생성 시 4자리 가입 코드를 무작위로 발급한다.
- 진행 중인 모임끼리는 4자리 가입 코드가 중복되지 않도록 발급한다.
- 완료되거나 삭제된 모임의 코드는 새로운 모임에서 다시 사용할 수 있다.
- 모임장은 공유 링크와 4자리 가입 코드를 다른 사람에게 전달할 수 있다.

### 3.3 모임 가입

- 사용자는 공유 링크 또는 홈 화면의 `모임 가입하기`에서 가입을 시작한다.
- 홈 화면에서 가입할 때는 생성된 모임의 4자리 가입 코드를 입력한다.
- 공유 링크에는 대상 모임 정보가 포함되며, 사용자는 링크 접속 후 4자리 가입 코드를 입력한다.
- 가입 화면에는 계정 닉네임을 기본값으로 표시한다.
- 사용자는 해당 모임에서 사용할 닉네임을 최대 20글자까지 수정할 수 있다.
- 현재 인원이 정원에 도달하면 새로운 사용자는 가입할 수 없다.
- 모임이 투표를 시작했거나 완료·삭제된 상태라면 새로 가입할 수 없다.

### 3.4 내 장소와 후보 장소

- 로그인한 사용자는 누구나 지도에서 관심 장소를 `내 장소`에 저장할 수 있다.
- 이미 `내 장소`에 저장된 장소를 지도에서 선택하면 `내 장소 등록하기` 대신 `장소 등록 해제` 버튼을 표시한다.
- 장소 저장 시 다음 항목을 각각 하나씩 선택한다.
  - 장소 목적: `스터디`, `카페`, `식사`, `술 한잔`
  - 장소 성격: `즐거운`, `조용한`, `격식있는`, `취기있는`
- 후보 선택 목록에는 모든 `내 장소`를 표시한다.
- 목적·성격이 모두 일치하는 장소, 하나만 일치하는 장소, 모두 불일치하는 장소 순으로 정렬한다.
- 같은 일치도 안에서는 장소명을 가나다순으로 정렬한다.
- 모두 불일치하는 장소는 투명도를 낮추고 `조건 불일치`를 표시하지만 선택할 수 있다.
- 모임장과 모임원은 각자 최대 2개의 후보 장소를 선택할 수 있다.
- 저장된 `내 장소`가 없거나 원하는 장소가 없으면 후보를 선택하지 않고 모임에 참여할 수 있다.
- 여러 사람이 네이버 장소 ID가 같은 장소를 선택하면 하나의 후보로 합친다.
- 합쳐진 후보에는 `추천한 사람 N명`을 표시한다.
- `내 장소`의 목적이나 성격을 변경할 때 진행 중인 모임 후보에 반영할지 묻는다.
- 투표 생성 전에는 사용자가 선택한 경우 `이번 투표에도 반영`할 수 있다.
- 변경 후 모임 목적과 성격이 모두 불일치해도 이미 선택한 후보는 유지하며, 후보 선택 화면에서 `조건 불일치`로 표시한다.
- 투표 생성 후에는 후보가 고정되므로 `내 장소` 변경이나 등록 해제를 기존 투표에 반영하지 않는다.

### 3.5 투표

- 전체 후보가 2개 이상이면 모임장이 투표를 시작할 수 있다.
- 정원이 모두 참여하지 않아도 투표를 시작할 수 있다.
- 기존의 후보 최소 5개, 최대 10개 규칙은 사용하지 않는다.
- 사용자는 최대 2개까지만 후보를 제출하며, 모임 전체 후보 수에는 별도 상한을 두지 않는다.
- 투표 생성 시 후보 목록을 고정한다.
- 후보가 `N`개면 각 사용자는 `N-1`회의 A/B 선택을 진행한다.
- 각 A/B 선택에서 선택받은 후보에 1표를 부여한다.
- 투표를 완료한 사용자는 후보별 실시간 득표수를 확인할 수 있다.
- 사용자가 투표 도중 화면을 닫아도 마지막으로 완료한 라운드 다음부터 이어서 진행한다.
- 모임장은 투표를 수동으로 종료한다.
- 투표 미완료 인원이 있으면 종료 전에 확인창을 표시한다.
- 모임장이 종료를 확정하면 현재까지 서버에 저장된 모든 A/B 선택을 집계하고 추가 투표를 막는다.

### 3.6 동점 처리

득표수가 같은 후보가 있으면 다음 순서로 처리한다.

1. 더 많은 모임원이 추천한 장소를 높은 순위로 표시한다.
2. 추천 인원 수도 같으면 공동 1위로 표시한다.
3. 공동 1위 중 최종 장소는 모임장이 선택한다.
4. 단독 1위이면 투표 종료 시 해당 장소를 자동으로 최종 장소로 확정한다.

### 3.7 모임 탈퇴·내보내기·삭제

- 모임원은 투표 생성 전까지만 탈퇴할 수 있다.
- 모임장은 탈퇴할 수 없으며 모임 삭제만 할 수 있다.
- 모임장은 투표 생성 전까지만 모임원을 내보낼 수 있다.
- 모임원이 탈퇴하거나 내보내지면 해당 모임원이 추천한 후보 기록도 제거한다.
- 다른 추천자가 남아 있지 않은 후보는 후보 목록에서도 제거한다.
- 모임장은 모든 단계에서 모임을 삭제할 수 있다.
- 삭제 전에는 현재 진행 상태와 관계없이 경고창을 표시한다.
- 삭제 기능은 주요 행동보다 연하게 표시하거나 더보기 메뉴 안에 배치해 실수로 누르기 어렵게 한다.
- 삭제된 모임의 공유 링크와 가입 코드는 더 이상 사용할 수 없다.
- 탈퇴하거나 내보내진 사용자는 투표 생성 전이고 정원에 여유가 있다면 같은 코드로 재가입할 수 있다.
- 재가입하더라도 이전 후보는 자동으로 복구하지 않으며 다시 선택한다.

## 4. 전체 사용자 흐름

```text
damo.com 접속
  → 로그인 또는 회원가입
      ├─ 테스트: 아이디·닉네임·비밀번호로 즉시 가입
      └─ OAuth: 카카오·네이버·구글 제공자별 별도 계정
  → 홈 화면
      ├─ 모임 만들기
      │   → 모임명·정원·날짜·시각·목적·성격 선택
      │   → 가입 코드와 공유 링크 생성
      │   → 내 장소에서 후보 최대 2개 선택
      │   → 모임 관리 화면
      ├─ 모임 가입하기
      │   → 4자리 가입 코드 입력
      │   → 모임별 닉네임 확인·수정
      │   → 내 장소에서 후보 최대 2개 선택
      │   → 모임 상세 화면
      ├─ 지도
      │   → 역 이름 검색
      │   → 장소 상세 확인
      │   ├─ 미등록 장소 → 목적·성격 선택 → 내 장소에 저장
      │   └─ 등록 장소 → 장소 등록 해제
      └─ 내 장소
          → 저장 장소 조회·변경·등록 해제
          → 변경 시 이번 투표 반영 여부 선택

모임장: 후보 2개 이상 확인
  → 투표 시작
  → 투표 생성 확인
  → 모든 참여자의 홈에 투표 알림 표시

모임장과 모임원
  → 모임 카드에서 투표 화면 진입
  → N-1회 A/B 선택
  → 실시간 득표수 확인
  → 개인 투표 완료 시 해당 사용자의 알림 해제

모임장
  → 투표 종료
  → 미완료 인원이 있으면 종료 여부 재확인
  → 현재까지 저장된 선택 집계
      ├─ 단독 1위 → 최종 장소 자동 확정
      └─ 공동 1위 → 모임장이 최종 장소 선택
```

## 5. 공통 화면 구조

### 5.1 하단 내비게이션

로그인 이후 모든 주요 화면 하단에 다음 내비게이션을 표시한다.

| 메뉴 | 이동 화면 |
| --- | --- |
| 홈 | 가입·생성한 모임을 관리하는 화면 |
| 지도 | 장소를 검색하고 `내 장소`에 저장하는 화면 |
| 내 장소 | 저장한 장소를 조회·변경·등록 해제하는 화면 |

투표 알림이 있으면 홈 아이콘에 빨간색 동그라미를 표시한다.

### 5.2 로그인 화면

표시 요소:

- 테스트용 아이디·닉네임·비밀번호 입력
- 테스트용 `즉시 가입`, `로그인` 버튼
- 카카오 로그인
- 네이버 로그인
- 구글 로그인

처리 흐름:

1. 사용자가 로그인 방식을 선택한다.
2. 인증에 성공하면 홈 화면으로 이동한다.
3. 초대 링크에서 로그인 화면으로 이동한 경우에도 인증 후 홈 화면으로 이동한다.
4. 사용자는 홈의 `모임 가입하기`에서 공유받은 코드를 입력한다.
5. 인증에 실패하면 로그인 화면에 오류를 표시한다.

배포 시에는 아이디·닉네임·비밀번호 입력과 테스트 가입·로그인 버튼을 제거한다.

## 6. 홈 화면

### 6.1 기본 구성

홈 화면은 로그인 직후 표시되는 모임 관리 화면이다.

표시 요소:

- 현재 사용자가 가입한 모임 목록
  - 상단 `진행 중인 모임`
  - 하단 `완료된 모임`
- 각 모임을 나타내는 카드
- 홈 상단 요약 배너
- 닉네임이 표시되는 프로필 버튼
- 하단의 `모임 만들기`, `모임 가입하기` 버튼
- 하단 내비게이션

요약 배너는 처음에는 펼쳐진 상태이며 누를 때마다 설명 영역을 접거나 다시 펼친다. 접힘 상태는 새로고침 후 유지하지 않는다. 프로필 버튼은 닉네임 길이에 맞춰 너비가 변하는 둥근 사각형으로 표시하되, 최대 너비를 넘는 닉네임은 말줄임표로 처리한다.

모임 카드 표시 예:

```text
7/29 파티룸
모임장 · 현재 4/6명
```

또는:

```text
금요일 저녁 모임
모임원 · 현재 4/6명
```

카드에는 다음 정보를 표시한다.

- 모임 이름
- 사용자의 역할: `모임장` 또는 `모임원`
- 현재 인원과 정원
- 모임 목적
- 모임 성격
- 만나는 날짜와 시각
- 현재 상태: `후보 선택 중`, `투표 진행 중`, `투표 완료`

목록 구분:

- `진행 중인 모임`에는 일정이 지나지 않은 후보 선택 중, 투표 진행 중, 최종 장소 선택 중인 모임을 표시한다.
- `완료된 모임`에는 최종 장소가 확정된 모임과 날짜가 지난 모임을 표시한다.
- 완료된 모임 카드는 진행 중인 모임보다 연한 배경과 낮은 강조도로 표시한다.
- 날짜가 지난 미완료 모임은 서버가 실제로 완료 처리한다: 진행 중이던 투표는 함께 종료하고, 단독 1위가 있으면 최종 장소로 저장하며, 공동 1위이거나 무득표면 최종 장소 없이 완료한다. 완료 후에는 카드를 열어도 후보 변경이나 투표를 이어갈 수 없다.
- 완료 영역은 최근 일정부터 표시하고 지난 회차를 계속 누적한다.
- 삭제된 모임은 홈에 표시하지 않는다.

### 6.2 스크롤과 플로팅 버튼

- 모임 목록만 세로로 스크롤한다.
- `모임 만들기`와 `모임 가입하기` 버튼은 화면 하단에 고정한다.
- 목록을 스크롤해도 두 버튼은 계속 표시한다.

### 6.3 투표 알림

모임장이 투표를 생성하면 아직 투표하지 않은 참여자의 화면을 다음과 같이 변경한다.

- 홈 내비게이션 아이콘에 빨간색 동그라미 표시
- 해당 모임 카드에 `투표 진행 중` 표시
- 해당 모임 카드의 테두리를 분홍색으로 변경
- 카드 배경을 더 연한 분홍색으로 변경
- 해당 모임 카드를 눈에 거슬리지 않는 속도로 깜빡이게 표시

알림 해제 규칙:

- 사용자가 해당 모임의 투표를 모두 완료하면 빨간색 동그라미와 카드 깜빡임을 해제한다.
- 투표 완료 후에도 카드의 `투표 진행 중` 문구는 모임 전체 투표가 끝날 때까지 유지한다.
- 모임장이 투표를 종료하면 아직 투표하지 않은 참여자의 빨간색 동그라미와 카드 깜빡임도 해제한다.
- 투표 종료 후 카드는 `투표 완료` 또는 `최종 장소 선택 중` 상태로 변경한다.
- MVP에서는 홈 상태를 5초 간격으로 다시 조회한다.

## 7. 지도 화면

### 7.1 장소 탐색

표시 요소:

- 상단 역 이름 검색창
- 두 글자 이상 입력 시 최대 5개의 장소 검색어 미리보기
- 네이버 지도
- 지도 마커
- 선택한 검색 결과 마커 위의 장소 정보창
- 지도 하단에서 좌우로 넘길 수 있는 검색 결과 카드
- 선택한 장소의 상세 정보
- 저장 상태에 따른 `내 장소 등록하기` 또는 `장소 등록 해제` 버튼

처리 흐름:

1. 사용자가 상단 검색창에 역 이름을 입력한다.
2. 두 글자 이상 입력하고 350ms 동안 추가 입력이 없으면 장소명, 카테고리, 주소 미리보기를 표시한다.
3. 사용자가 미리보기 또는 검색 버튼을 선택하면 해당 검색 결과를 지도 마커로 표시한다.
4. 검색 결과는 지도 하단에 장소명, 카테고리, 주소가 포함된 가로 카드 목록으로 표시하며 사용자는 좌우 스와이프로 넘긴다.
5. 사용자가 검색 결과 마커 또는 하단 카드를 선택하면 지도 안의 정보창과 상세 카드에 장소명, 주소, 카테고리를 표시하고 선택한 하단 카드가 중앙에 오도록 이동한다.
6. 저장하지 않은 장소가 선택된 동안 `내 장소 등록하기` 버튼을 활성화한다.
7. 사용자가 등록 버튼을 누르면 장소 분류 선택 화면을 표시한다.
8. 이미 저장된 장소라면 `장소 등록 해제` 버튼을 표시한다.
9. 모임 후보 선택 화면의 `지도에서 새 장소 찾기`로 진입해 저장했다면 `내 장소에 추가되었어요. 현재 모임에도 후보로 등록할까요?`를 표시한다.
10. `다음에`를 누르면 후보로 추가하지 않고 해당 모임 후보 선택 화면으로 돌아간다.
11. `추가하기`를 누르면 현재 후보에 추가하고 해당 모임 후보 선택 화면으로 돌아간다.
12. 이미 본인의 후보가 2개라면 `이미 후보 2개가 등록되어 있어요. 모임 페이지에서 후보를 변경해주세요.`와 `확인` 버튼을 표시한다.
13. 위 후보 추가 안내는 하단 내비게이션의 일반 지도 화면으로 들어온 경우에는 표시하지 않는다.
14. 등록 해제를 누르면 투표 생성 전 후보도 함께 취소할지 사용자에게 묻는다.
15. 사용자가 이번 투표 반영을 선택하면 해당 사용자의 추천을 후보에서 제거한다.
16. 이번 투표에 반영하지 않으면 `내 장소`에서만 숨기고 기존 후보 추천은 유지한다.
17. 투표가 이미 생성됐다면 고정된 후보에는 영향을 주지 않는다.

네이버 Dynamic Map의 기본 지도 타일에 표시된 임의 상호명은 장소 ID나 상세 정보를 제공하지 않으므로 직접 선택 대상으로 사용하지 않는다. DAMO 검색 API가 반환해 생성한 마커만 장소 상세 선택 대상으로 사용한다.

### 7.2 장소 분류 선택

사용자는 다음 항목을 각각 하나씩 선택한다.

- 목적: `스터디`, `카페`, `식사`, `술 한잔`
- 성격: `즐거운`, `조용한`, `격식있는`, `취기있는`

`확인`을 누르면 네이버 장소 ID, 장소 정보, 목적, 성격을 `내 장소`에 저장한다.

### 7.3 저장된 장소 변경

저장된 장소의 목적이나 성격을 변경하면 다음 확인창을 표시한다.

```text
진행 중인 이번 투표에도 변경사항을 반영할까요?

[내 장소만 변경] [이번 투표에도 반영]
```

- `내 장소만 변경`: 개인 `내 장소` 정보만 변경한다.
- `이번 투표에도 반영`: 아직 투표가 생성되지 않은 모임 후보에도 변경사항을 반영한다.
- 이 버튼을 누르면 사용자가 활성 참여 중이고, 상태가 `RECRUITING`이며, 해당 장소를 자신의 후보로 등록한 모임만 표시한다.
- 여러 모임에 같은 장소를 후보로 제출했다면 반영 대상 모임을 복수선택할 수 있다.
- 변경 후 모임 목적과 성격이 모두 일치하지 않아도 사용자가 선택한 후보는 유지한다.
- 투표가 생성된 모임에는 변경사항을 반영하지 않는다.

## 8. 내 장소 화면

표시 요소:

- 저장된 장소 목록
- 장소별 작은 대표 사진
- 장소명
- 저장한 목적과 성격

상호작용:

1. 장소 항목을 오른쪽으로 슬라이드한다.
2. `변경`, `등록 해제` 버튼을 표시한다.
3. `변경`을 누르면 목적과 성격을 다시 선택할 수 있다.
4. 변경 완료 전에 `내 장소만 변경`, `이번 투표에도 반영` 중 하나를 선택한다.
5. `등록 해제`를 누르면 확인 후 `내 장소`에서 숨긴다.
6. 투표 생성 후 등록을 해제해도 고정된 후보와 진행 중인 투표에는 영향을 주지 않는다.
7. 장소 항목을 누르면 장소 상세 정보를 표시한다.

빈 상태:

- 저장된 장소가 없으면 안내 문구와 `지도에서 장소 찾기` 버튼을 표시한다.

## 9. 모임 생성 흐름

### 9.1 모임 생성 화면

입력·선택 요소:

- 모임 이름
- 정원
  - 가운데에 현재 숫자를 표시한다.
  - 왼쪽 `-`, 오른쪽 `+`로 조정한다.
  - 가운데 숫자를 누르면 인원수를 직접 입력할 수 있다.
  - 최소 2명이며 최대 인원에는 제한을 두지 않는다.
- 만나는 날짜
- 만나는 시각
  - 오전/오후 선택
  - 시는 `1~12`에서 선택
  - 분은 `00`, `30` 중 하나 선택
- 모임 목적 단일 선택
  - 스터디
  - 카페
  - 식사
  - 술 한잔
- 모임 성격 단일 선택
  - 즐거운
  - 조용한
  - 격식있는
  - 취기있는

처리 흐름:

1. 사용자가 필수값을 모두 선택한다.
   - 모임 이름은 최대 20글자로 입력한다.
2. `모임 생성하기`를 누른다.
3. 시스템은 모임을 생성하고 사용자를 모임장으로 등록한다.
4. 진행 중인 다른 모임과 중복되지 않는 무작위 4자리 가입 코드와 공유 링크를 생성한다.
5. 모임장의 후보 선택 화면으로 이동한다.

### 9.2 모임장 후보 선택

1. `해당 모임은 [목적][성격] 성격의 모임이에요` 안내를 표시한다.
2. 모든 `내 장소`를 일치도 내림차순, 같은 일치도에서는 가나다순으로 표시한다.
3. 모두 불일치하는 장소는 흐리게 표시하고 `조건 불일치`를 붙이되 선택은 허용한다.
4. 모임장은 최대 2개의 장소를 선택한다.
5. `지도에서 새 장소 찾기`를 선택하면 모임 정보를 유지한 채 지도 화면으로 이동한다.
6. 후보를 선택하지 않고 넘어갈 수 있다.
7. 선택을 완료하면 모임 관리 화면으로 이동한다.

### 9.3 모임 관리 화면

표시 요소:

- 모임 이름
- 모임 목적과 성격
- 만나는 날짜와 시각
- 4자리 가입 코드
- 공유 링크
- 현재 인원/정원
- 참여자 목록
- 현재 후보 목록
- 후보별 추천한 사람 수
- 시그니처 컬러 `투표 시작` 버튼
- 연하게 표시하거나 더보기 메뉴에 배치한 `모임 삭제` 기능

모임 목적·성격, 날짜·시간, 현재 인원·정원은 왼쪽에 압축해 표시한다. 모임장에게만 가입 코드와 `초대 복사` 버튼을 같은 영역 오른쪽에 나란히 표시한다.

`내 후보 변경` 링크는 `내 장소에서 가져오기`로 표시한다. 후보가 4개 이상이면 후보 영역 안에서만 세로 스크롤한다. 후보를 누르면 위치 확인 전용 지도 화면으로 이동하며, 이 화면에는 해당 장소의 실제 지도 위치와 하단 상세정보를 표시하고 검색·저장 기능은 제공하지 않는다.

모임장에게는 모임 상세 화면 하단의 일반 `모임 만들기`, `모임 가입하기` 대신 시그니처 컬러 `투표 시작` 버튼을 표시한다.

투표 시작 버튼:

- 후보가 0~1개이면 비활성화한다.
- 후보가 2개 이상이면 활성화한다.
- 정원이 모두 차지 않아도 활성화할 수 있다.

참여자 관리:

- 모임장은 투표 생성 전까지 모임원을 내보낼 수 있다.
- 내보내기 전 확인창을 표시한다.
- 내보낸 모임원이 추천한 장소도 해당 모임 후보에서 제거한다.
- 같은 장소를 다른 모임원이 추천했다면 후보는 유지하고 추천 인원 수만 줄인다.
- 투표 생성 후에는 참여자 내보내기 기능을 비활성화한다.

모임 삭제:

- 모임장은 모임 상태와 관계없이 삭제할 수 있다.
- 삭제 기능은 실수로 누르기 어렵게 주요 버튼과 떨어뜨리고 시각적으로 약하게 표시한다.
- 삭제를 누르면 현재 진행 중인 가입, 후보, 투표 데이터에 접근할 수 없게 된다는 경고창을 표시한다.
- 삭제를 확정하면 해당 공유 링크와 가입 코드를 더 이상 사용할 수 없다.

## 10. 모임 가입 흐름

### 10.1 홈에서 가입

1. 사용자가 `모임 가입하기`를 누른다.
2. 4자리 가입 코드 입력 화면을 표시한다.
3. 입력한 코드에 해당하는 진행 중인 모집 상태의 모임을 조회한다.
4. 모임이 존재하고 정원에 여유가 있으면 닉네임 확인 화면으로 이동한다.

### 10.2 공유 링크에서 가입

1. 사용자가 공유 링크를 연다.
2. 로그인하지 않았다면 로그인 화면으로 이동한다.
3. OAuth 로그인 후 홈 화면으로 이동한다.
4. 사용자가 홈의 `모임 가입하기`를 누른다.
5. 사용자가 공유받은 4자리 가입 코드를 입력한다.
6. 코드가 맞으면 닉네임 확인 화면으로 이동한다.
7. 모임이 투표를 시작했거나 완료·삭제됐다면 가입을 막고 현재 상태를 안내한다.

### 10.3 모임 닉네임 확인

- 계정 닉네임을 기본값으로 표시한다.
- 사용자는 해당 모임에서 사용할 닉네임을 최대 20글자까지 수정할 수 있다.
- `가입하기`를 누르면 정원을 다시 확인한 후 모임원으로 등록한다.
- 이전에 탈퇴하거나 내보내진 사용자도 투표 생성 전이고 정원에 여유가 있으면 재가입할 수 있다.

### 10.4 모임원 후보 선택

1. `해당 모임은 [목적][성격] 성격의 모임이에요` 안내를 표시한다.
2. 모든 `내 장소`를 일치도 내림차순, 같은 일치도에서는 가나다순으로 표시한다.
3. 모두 불일치하는 장소는 흐리게 표시하고 `조건 불일치`를 붙이되 선택은 허용한다.
4. 사용자는 최대 2개의 장소를 선택한다.
5. `지도에서 새 장소 찾기`를 선택하면 모임 정보를 유지한 채 지도 화면으로 이동한다.
6. 후보를 선택하지 않고 넘어갈 수 있다.
7. 같은 네이버 장소 ID가 이미 후보로 등록되어 있으면 기존 후보에 추천 인원 수만 추가한다.
8. 선택을 완료하면 모임 상세 화면으로 이동한다.

### 10.5 모임 탈퇴

- 모임원은 투표 생성 전까지만 탈퇴할 수 있다.
- 탈퇴 전 확인창을 표시한다.
- 탈퇴하면 해당 모임원이 추천한 후보 기록을 함께 제거한다.
- 같은 장소를 다른 모임원이 추천했다면 후보는 유지하고 추천 인원 수만 줄인다.
- 추천자가 남지 않은 후보는 후보 목록에서 제거한다.
- 투표 생성 후에는 후보와 참여자가 고정되므로 탈퇴할 수 없다.
- 모임장은 탈퇴할 수 없고 모임 삭제만 할 수 있다.
- 탈퇴하거나 내보내진 사용자가 재가입하면 이전 후보는 복구하지 않고 후보 선택 화면부터 다시 진행한다.

## 11. 투표 생성 흐름

### 11.1 투표 시작 확인

모임장이 분홍색 `투표 시작` 버튼을 누르면 확인 창을 표시한다.

```text
투표를 시작할까요?

[취소] [투표 생성]
```

- `취소`: 확인 창을 닫고 모임 관리 화면으로 돌아간다.
- `투표 생성`: 현재 후보 목록과 추천자 정보를 스냅샷으로 고정하고 투표를 시작한다.
- 후보가 2개 미만이면 투표를 생성할 수 없다.

### 11.2 투표 생성 직후

투표를 생성하면 다음 상태를 자동으로 반영한다.

- 모임장과 모든 모임원에게 투표 가능 상태를 전달한다.
- 아직 투표하지 않은 사용자의 홈 아이콘에 빨간색 동그라미를 표시한다.
- 해당 사용자의 홈에서 모임 카드를 분홍색 계열로 깜빡이게 표시한다.
- 해당 모임 카드에 `투표 진행 중`을 표시한다.
- 후보 선택과 변경을 막는다.
- 모임원의 탈퇴와 모임장에 의한 내보내기를 막는다.
- 모임장에게 `투표 종료` 기능을 표시한다.

사용자가 해당 모임 카드를 누르면 A/B 투표 화면으로 이동한다.

## 12. A/B 투표 화면

### 12.1 최초 후보 확인

1. 개인 투표 세션에 처음 진입하면 고정된 전체 후보를 목록으로 표시한다.
2. 목록 하단의 `A/B 투표 시작` 버튼을 누르면 첫 번째 라운드로 이동한다.
3. 후보를 누르면 위치 확인 전용 지도 화면에서 실제 위치와 상세정보를 볼 수 있다.
4. 투표를 진행한 뒤 다시 들어오면 전체 후보 확인을 생략하고 완료하지 않은 다음 라운드를 표시한다.

### 12.2 후보 배정

- 투표 생성 시점의 전체 후보를 사용한다.
- 같은 네이버 장소 ID의 후보는 하나만 포함한다.
- 사용자별로 후보 순서를 무작위로 섞는다.
- 후보가 `N`개면 `N-1`라운드를 만든다.

예: 후보 5개

```text
무작위 순서: ① ② ③ ④ ⑤

1라운드: A=①, B=②
2라운드: 직전 승자 vs ③
3라운드: 직전 승자 vs ④
4라운드: 직전 승자 vs ⑤
```

### 12.3 라운드 처리

- 각 라운드에는 후보 두 곳만 표시한다.
- 사용자가 선택한 후보는 현재 A/B 자리를 유지한다.
- 다음 후보는 직전 패배 후보가 있던 자리에 표시한다.
- 각 선택에서 선택받은 후보에 1표를 추가한다.
- 선택 결과를 저장한 후 다음 라운드로 이동한다.
- 같은 라운드가 중복 제출되면 한 번만 반영한다.
- 각 라운드 선택은 다음 화면으로 이동하기 전에 서버에 저장한다.
- 사용자가 브라우저를 닫거나 연결이 끊기면 마지막으로 저장한 라운드 다음부터 이어서 진행한다.

### 12.4 개인 투표 완료

마지막 선택이 저장되면 다음과 같이 처리한다.

- 해당 사용자의 투표 상태를 `완료`로 변경한다.
- 홈 아이콘의 빨간색 동그라미를 제거한다.
- 해당 모임 카드의 분홍색 깜빡임을 해제한다.
- 모임 카드의 `투표 진행 중` 문구는 유지한다.
- 실시간 결과 화면으로 이동한다.

### 12.5 투표 진행 중 이탈과 복귀

1. 사용자가 모임 카드에서 다시 투표 화면에 들어온다.
2. 시스템은 개인별 투표 진행 상태와 마지막으로 완료한 라운드를 조회한다.
3. 완료하지 않은 다음 라운드를 표시한다.
4. 이미 저장된 라운드를 다시 제출하면 최초 선택만 유지하고 중복 득표를 만들지 않는다.

## 13. 실시간 결과 화면

표시 요소:

- 후보별 현재 순위
- 후보별 현재 득표수
- 후보별 추천한 사람 수
- 공동 1위 여부
- 아직 결과가 바뀔 수 있다는 안내
- 투표를 완료한 인원과 미완료 인원 수

집계 규칙:

1. 모든 사용자의 각 A/B 선택을 후보별 1표로 합산한다.
2. 득표수가 높은 후보를 높은 순위로 표시한다.
3. 득표수가 같으면 추천한 모임원 수가 많은 후보를 높은 순위로 표시한다.
4. 추천 인원 수도 같으면 공동 1위로 표시한다.
5. 단독 1위는 투표 종료 시 최종 장소로 자동 확정한다.
6. 공동 1위가 있으면 모임장에게 최종 장소 선택 기능을 제공한다.

결과는 다른 사용자의 투표가 저장될 때 자동으로 갱신한다.

- MVP에서는 결과 API를 5초 간격으로 조회해 자동 갱신한다.
- 화면을 벗어나거나 브라우저가 백그라운드 상태가 되면 불필요한 조회를 중단한다.
- 사용량이 늘면 같은 결과 구조를 유지하면서 WebSocket 방식으로 변경한다.

## 14. 투표 종료와 최종 장소 확정

### 14.1 모임장의 수동 종료

모임장은 투표 진행 중 `투표 종료`를 누를 수 있다.

모든 참여자가 투표를 완료했다면 종료 확인 후 현재 결과를 확정한다.

미완료 인원이 있다면 다음 확인창을 표시한다.

```text
아직 투표를 완료하지 않은 인원이 있습니다.
그래도 종료할까요?

[기다릴게요] [그래도 종료]
```

- `기다릴게요`: 확인창을 닫고 투표를 계속 진행한다.
- `그래도 종료`: 추가 A/B 선택을 막고 현재까지 서버에 저장된 모든 선택을 집계한다.
- 일부 라운드만 완료한 사용자의 저장된 선택도 각각 1표로 포함한다.
- 종료 후 미완료 사용자의 홈 투표 알림을 해제한다.

### 14.2 단독 1위

1. 득표수와 추천 인원 수 규칙을 적용해 순위를 계산한다.
2. 단독 1위가 한 곳이면 해당 장소를 최종 장소로 자동 확정한다.
3. 모임 상태를 `투표 완료`로 변경한다.
4. 모든 모임원에게 최종 장소를 표시한다.

### 14.3 공동 1위

1. 득표수와 추천 인원 수가 모두 같은 1위 후보를 공동 1위로 표시한다.
2. 모임 상태를 `최종 장소 선택 중`으로 변경한다.
3. 모임장에게만 공동 1위 후보 중 하나를 선택하는 기능을 제공한다.
4. 모임장이 장소를 선택하면 최종 장소를 저장하고 모임 상태를 `투표 완료`로 변경한다.
5. 공동 1위가 아닌 장소는 최종 장소로 선택할 수 없다.

### 14.4 최종 결과 화면

- 확정된 1위 장소는 사진, 장소명, 주소, 득표수, 추천 인원 수가 포함된 상세 카드로 표시한다.
- 나머지 장소는 순위, 장소명, 득표수, 막대그래프만 표시한다.
- 막대 길이는 1위 득표수를 100%로 두고 상대 비율로 계산한다.
- 하단에 `홈으로`, `모임으로` 버튼을 나란히 표시한다.

## 15. 다시 만나기와 정기 모임

### 15.1 진행 중 모임을 정기화

1. 진행 중 모임의 모임장이 우상단 `...` 메뉴를 연다.
2. `정기적으로 만나기`를 선택한다.
3. 현재 모임을 복제하지 않고 반복 규칙만 저장한다.
4. 현재 모임의 가입 코드, 모임원, 후보, 투표 상태는 그대로 유지한다.
5. 현재 회차의 최종 장소가 확정되면 같은 가입 코드를 사용하는 다음 회차 하나를 자동 생성한다.

반복 주기는 `매주`, `매달`, `직접 입력` 중 하나를 선택한다. 직접 입력 시 다음 회차 날짜·시각을 고르며 분은 모바일 선택 UI에서 `00~59` 전체를 위아래로 넘겨 선택할 수 있다.

### 15.2 완료된 모임에서 다시 만나기

1. 완료되었거나 날짜가 지난 모임의 모임장이 우상단 `...` 메뉴를 연다.
2. `다시 만나기`를 선택한다.
3. 기존 모임과 연결된 새로운 회차 생성 화면을 표시한다.
4. 모임명, 목적, 성격, 정원, 가입 코드는 이전 회차 값을 기본으로 사용한다.
5. 날짜는 현재 날짜로부터 일주일 뒤를 기본 선택하고 모임장이 직접 변경할 수 있다.
6. 시각의 분은 `00~59` 전체를 위아래로 넘겨 선택할 수 있다.
7. 이전 모임원은 모두 선택된 상태로 표시한다. 모임장은 제외할 수 없고 다른 모임원은 눌러서 제외할 수 있다.
8. 생성된 회차의 후보와 투표 기록은 비어 있는 상태로 시작한다.

`정기적으로 만나기`를 선택하면 다음 옵션을 표시한다.

- `매주`: 같은 요일과 시각
- `매달`: 같은 일자와 시각
- `직접 입력`: 다음 회차 날짜를 달력에서 선택

현재 회차의 최종 장소가 확정되면 다음 회차 하나만 자동으로 생성한다. 매주·매달 설정은 다음 회차에도 유지하고, 직접 입력은 지정한 한 회차를 생성한 뒤 자동 반복을 종료한다. 푸시 알림은 이후 범위로 둔다.

## 16. 예외 및 오류 흐름

| 상황 | 처리 |
| --- | --- |
| 로그인하지 않은 사용자가 보호 화면 접근 | 로그인 화면으로 이동하고 로그인 후 홈 화면으로 이동 |
| OAuth 인증 실패 | 로그인 화면에 실패 안내와 재시도 버튼 표시 |
| 잘못된 4자리 가입 코드 | 입력 화면에 오류 표시 |
| 공유 링크와 가입 코드가 일치하지 않음 | 가입을 막고 코드 재입력 요청 |
| 투표 시작·완료·삭제된 모임 코드 입력 | 가입을 막고 현재 모임 상태 안내 |
| 모임 정원 초과 | 가입을 막고 `정원이 모두 찼습니다` 표시 |
| 일치하는 내 장소가 없음 | 후보 없이 가입 가능하며 지도 또는 내 장소로 이동할 수 있는 버튼 제공 |
| 한 사용자가 3번째 후보 선택 | 선택을 막고 최대 2개 안내 표시 |
| 같은 장소를 여러 명이 추천 | 하나의 후보로 합치고 추천 인원 수 증가 |
| 내 장소 변경 후 모임 조건과 불일치 | `이번 투표에도 반영`을 선택했다면 해당 사용자의 추천만 제거 |
| 탈퇴하거나 내보낸 사용자의 후보 | 해당 사용자의 추천을 제거하고 다른 추천자가 없으면 후보도 제거 |
| 후보가 2개 미만 | 투표 시작 버튼 비활성화 |
| 투표 생성 후 후보 변경 시도 | 변경을 막고 `투표가 이미 시작되었습니다` 표시 |
| 투표 생성 후 탈퇴·내보내기 시도 | 변경을 막고 `투표 참여자가 이미 확정되었습니다` 표시 |
| 같은 라운드 중복 제출 | 최초 제출만 반영 |
| 투표 도중 화면 종료 | 마지막 저장 라운드 다음부터 재개 |
| 미완료 인원이 있는 상태에서 투표 종료 | `기다릴게요`, `그래도 종료` 선택 표시 |
| 투표 종료 후 선택 제출 | 저장을 막고 확정된 결과 화면으로 이동 |
| 모임 삭제 시도 | 현재 상태에 맞는 경고창 표시 후 모임장만 삭제 가능 |
| 삭제된 모임 링크 접근 | 가입과 조회를 막고 삭제된 모임 안내 |
| 실시간 연결이 일시적으로 끊김 | 마지막으로 받은 상태를 표시하고 재연결 후 최신 상태로 갱신 |
